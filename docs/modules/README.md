# Modules

- [Firewall Module](firewall.md) — config-driven firewalld hardening; read before working on the firewall module.
- [Nautilus Module](nautilus.md) — the bookmark and symlink manager for the GNOME file manager; read before working on the nautilus module.
- [Notification System](notifications.md) — the journald-based notification daemon and its conventions; read before a module sends notifications or the daemon changes.
- [Torrent Module](torrent.md) — the VPN and qBittorrent container stack under Podman; read before working on the torrent module.
